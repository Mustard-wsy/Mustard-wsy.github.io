# 设计哲学与视觉规范

更新日期：2026-10-12。当前基线：用户再次确认保留的像素工作台，替代暖白纸面方案。

## 气质与边界

个人工作台：清晰、轻松、有生活感。首页通过留白、组件比例、轻微错位和像素边框形成辨识度，仅保留简短个人介绍与玩具架、文章库、项目目录三个主要入口；作品媒体与内容列表放在各自页面。不使用励志标语、章节编号或装饰寄语。

受蔚蓝的像素美术启发，但不搭建山景、关卡或悬浮平台。第一版没有 Shader、粒子、玻璃、光晕、鼠标跟随、全屏开场或自动播放。中文始终使用清晰的系统字体，像素只出现在边界和小图形中。

## 组件语法

- `.pixel-panel`：两层 CSS 多边形形成阶梯角，2px 深色边线，桌面 5px、手机 4px 硬阴影。不使用模糊阴影和旋转文字。
- 首页工作台最大宽度 900px，桌面为个人介绍与三个上下排列的入口组成两列，列间距 40px；第二个入口横向内收 20px，形成轻微错落。850px 以下单列，600px 以下入口间距 24px。以自然内容高度和充足留白呈现，不靠内容堆砌或固定画布。
- 窄屏按照 DOM 顺序自然单列。触控目标至少 44px；标题允许自然换行。
- 玩具架使用一个 `ToyCard` 模板，不能按 slug 写特殊样式。图片默认 16:10 完整容纳，无图时省略媒体。首页入口使用轻量静态像素图标，不加载玩具卡片或速览脚本。
- 身份区小图形是原创像素装饰；不代表用户真实头像。项目示意素材集中在 `fixtures/public/`，不混入正式发布。
- 游戏原素材尚未加入；后续选取时记录来源，避免整页变成游戏主题皮肤。

## 交互

标题、图片均是普通详情链接。速览是可选增强按钮，桌面打开右侧面板，手机打开底部面板，不撑开网格。原生 `dialog` 负责模态与焦点约束；关闭按钮、Esc、点击遮罩均可关闭，关闭后恢复触发按钮焦点。打开时锁定背景滚动。

无脚本时隐藏速览按钮，内容和导航仍可用。动效仅 180ms 轻微位移与透明度变化，遵守 `prefers-reduced-motion`。不在悬停中隐藏必要信息。

## 验收

文章目录标题统一为“目录”。850px 以上常驻正文右侧，默认展开；850px 及以下增强为右侧抽屉，入口固定在屏幕右侧中部。抽屉沿用浅冷面板、硬边框。入口用列表符号，视觉为 24×32px 窄片、1px 边框与短硬阴影；关闭用叉号，视觉为 24px 方块。两者保留透明的 44px 点击区域与可访问名称，避免大块直角按钮造成视觉压力。当前章节使用强调色、左侧标记与加粗显示，长目录可独立滚动；无脚本时保留正文前目录列表。

桌面和手机检查布局、长标题、无图、空内容、文章代码与公式。交互检查键盘打开、焦点、关闭、背景滚动以及详情链接。真实内容不足时不凑假进度、统计或空玩具。

文章库合集卡片采用两列像素面板，600px 以下单列；Logo 为 48px，缺省使用共享文件夹图标。手机全局页头为站名和导航两行，四个导航入口横向排列，避免站名被挤成多行。项目目录沿用玩具架的网格与共享速览。
