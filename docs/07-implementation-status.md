# 首轮实现与验收

日期：2026-10-09。阶段：可运行视觉预览，尚未公网发布。

## 已实现

- Astro 7 + TypeScript + 普通 CSS，静态阅读与导航，小型脚本渐进增强玩具速览。
- 首页、文章索引、专题、文章详情、玩具架、玩具详情、关于和 404。
- 浅冷色背景、阶梯像素边框、短硬阴影、错落组件与原创像素装饰。
- 无图作品使用紧凑信息卡，有图和视频通过可选字段呈现，不生成占位封面。
- 桌面多列、窄屏单列；文章目录在窄屏回到正文前。
- Markdown、代码高亮、KaTeX 数学公式、语义化 HTML。
- 草稿过滤、slug 和顺序唯一性、专题关系、日期与玩具媒体存在性校验。
- 根路径与仓库子路径支持，包括 Markdown 内的站点绝对路径链接。
- 预览样例与正式内容分开加载、分目录输出，预览页面有 noindex 标记。

## 验证方法

`npm test` 会构建生产、样例与 `/Blog/` 子路径三个版本，检查内链、资源文件、目录锚点、草稿隔离、生产空状态及公式/代码输出。测试产物位于忽略提交的 `test-results/`。

`npm run check` 检查 Astro 和 TypeScript；`npm run format:check` 检查一致的代码格式。

本轮浏览器检查覆盖桌面 1280px 与手机 390px 的首页、文章页、侧边速览和底部速览，以及 Esc 关闭后焦点恢复、滚动锁定与页面横向宽度。自动测试不能替代实际视觉评审，也不代表所有浏览器都已验证。
