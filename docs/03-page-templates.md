# 信息架构与页面模板

状态：基础模板已实现，细节仍可在视觉评审后调整。更新日期：2026-10-12。

## 1. 路由与导航

以下为站点相对路径；部署到 GitHub Pages 子路径时统一添加配置的 base path。

| 路径                           | 页面       | 导航归属 |
| ------------------------------ | ---------- | -------- |
| `/`                            | 首页       | 站名     |
| `/writing/`                    | 文章库     | 文章库   |
| `/writing/collections/<path>/` | 合集索引   | 文章库   |
| `/projects/`                   | 项目目录   | 项目目录 |
| `/projects/<slug>/`            | 项目详情   | 项目目录 |
| `/writing/<slug>/`             | 文章详情   | 文章     |
| `/topics/<slug>/`              | 专题详情   | 文章     |
| `/toys/`                       | 玩具架     | 玩具     |
| `/toys/<slug>/`                | 玩具详情   | 玩具     |
| `/about/`                      | 关于       | 关于     |
| `/404.html`                    | 找不到页面 | 无       |

公开地址使用稳定 slug。标题变化不自动改变地址；迁移地址时考虑静态跳转页及内部链接更新。

## 2. 全局框架

```text
跳转正文（键盘聚焦时显示）
站名                            文章库 / 玩具架 / 项目目录 / 关于
细分隔线

页面内容

细分隔线
站名                            关于 / 已配置的外部入口
```

窄屏将站名与导航分成两行，四个导航入口横向排列，无需为了四个入口引入复杂抽屉。页尾链接未配置时不展示。

## 3. 首页模板

首页为轻量入口工作台：左侧站名、原创像素装饰、简短个人介绍与关于链接；右侧上下排列玩具架、文章库、项目目录三个整卡链接。组件高度随内容自然增长，以留白和像素边框形成吸引力，不使用固定画布。

手机依 DOM 顺序：个人介绍 → 玩具架入口 → 文章库入口 → 项目目录入口。保持键盘和阅读顺序稳定。入口是普通链接，无需脚本即可使用。

- 身份文案来自站点配置；站名为 `mustard-wiki`，简介表达笔记、实验与个人兴趣；首页不重复显示全局导航栏。
- 玩具架入口指向 `/toys/`，文章库入口指向 `/writing/`，项目目录入口指向 `/projects/`。
- 首页不读取内容集合，不展示具体作品、最近文章、专题列表、数量或内容空状态；正式与预览模式共享入口布局。
- 具体内容及空状态在玩具架、文章库和项目目录展示，专题入口位于相关文章详情。新增普通项目只需要 Markdown 和可选封面。

玩具架中的速览通过独立按钮打开：桌面侧边面板、手机底部面板。速览展示封面、简介、标签和完整项目链接；长文、视频与外链留在详情页。它不改变 URL，也不扰动卡片布局。标题和封面链接在禁用脚本时仍正常跳转。

## 4. 文章库与合集索引模板

`/writing/` 显示直属合集入口与根目录文章；`/writing/collections/<目录路径>/` 显示该目录的直属子合集与直属文章，不把所有后代文章堆在一页。文件夹可以嵌套，中文目录名保留并在 URL 中编码。

- 每个合集可配置标题、简介、Logo 和排序；没有配置时使用文件夹名与共享文件夹图标。
- 合集卡片采用像素面板与 48px Logo，桌面两列、600px 以下一列；目录标题的 Logo 同样完整容纳。
- 路径导航显示文章库及上级合集，当前目录不重复链接。
- 只展示至少包含一篇公开文章（含后代）的合集，空目录与仅草稿目录隐藏。
- 同目录文章按发布日期倒序，同日期按 slug；合集按可选 order，再按目录路径排序。
- 文章详情保持 `/writing/<slug>/`，移动目录不改变文章地址；返回链接指向所在目录。
- 既有专题是可选的跨目录阅读顺序，由文章详情的专题链接进入，不再作为文章库的主要组织方式。

## 5. 专题模板

顺序：返回文章 → 专题标题 → 简介 → 有序文章列表。

- 按文章的 `topicOrder` 排列，不以发布日期代替学习顺序。
- 可显示文章摘要和算法类别等标签。
- 不预先生成 100 个空题目位置，不把不存在的笔记伪装成可访问内容。
- 未公开文章不进入目录，目录相邻关系根据已公开内容计算。

## 6. 文章详情模板

```text
文章 / 所属专题（如有）
标题
摘要
发布日期 · 更新日期（发生实质更新时） · 标签

正文                                     目录（宽屏默认展开）
标题、段落、公式、代码、图、表格

所属专题：专题名
上一篇 / 下一篇（同专题阅读顺序）
返回文章列表
```

- 只有足够的小标题时显示目录；初始规则为至少 3 个二、三级标题。
- 宽屏（大于 850px）目录在正文侧面默认展开，保持吸顶，长目录独立滚动。
- 窄屏目录默认收进右侧抽屉，通过固定“目录”按钮打开；关闭按钮、Esc、遮罩与章节点击可关闭。抽屉打开时锁定背景滚动，关闭后恢复按钮焦点。
- 两种布局均根据正文标题的阅读位置高亮当前章节，使用 aria-current 标记。无脚本时目录回退为正文前的普通锚点列表，正文仍可阅读。
- 独立文章不强行生成上一篇/下一篇。
- 代码和宽表在各自容器内滚动，公式不得破坏整页宽度。
- 文章内链接、复制按钮和目录锚点具有可见反馈。

## 7. 玩具架模板

顺序：标题与介绍 → 统一网格。

- 宽屏最多三列，中等宽度两列，窄屏一列，以内容空间为准。
- 所有条目使用同一模板：预览、名称、描述、标签、可选状态。
- 条目链接到内部详情页，代码和演示入口放在详情页，避免整个卡片链接内再嵌按钮。
- 排序：有精选顺序的条目在前，其余按发布日期倒序，同日期按 slug。
- 第一版不按“简历价值”“技术含量”或点击量排序。

## 8. 玩具详情模板

```text
返回玩具架
名称
一句话介绍
日期 · 标签 · 可选状态

可选媒体区域（图片或用户主动播放的视频）
查看源码 / 打开演示 / 下载（按配置出现）

正文：可短可长
制作缘由、使用说明、实现想法、局限、后续打算
```

- 无媒体时直接显示链接和正文，不保留空框。
- 无外部链接时仍然是有效条目，不显示禁用按钮。
- 演示默认使用外链。嵌入式演示属于后续能力，需有复用需求再设计。
- 视频不自动播放；截图、录屏和外链足以展示不能在线运行的项目。
- 状态变化不删除旧记录。短内容无需填满所有建议章节。

## 9. 关于与 404

关于页包括个人介绍、建立网站的缘由、兴趣与可选联系链接。不强制提供简历、学校全名或其他私人信息。

404 显示简短说明、首页及文章/玩具入口，不通过玩笑阻碍访客恢复浏览。

## 10. 通用状态验收

每个相关模板至少验证：无内容、一条内容、多条内容、长中文标题、无图片、缺少可选链接、窄屏、键盘操作。

预览环境可以有测试样本，但必须与正式内容隔离，不能进入公开列表、RSS 和站点图。

## 11. 项目目录

项目目录与玩具架使用同一网格、卡片、速览和 `WorkDetail` 详情模板，分别读取 `content/projects/` 与 `content/toys/`，路由分别为 `/projects/` 与 `/toys/`。元数据、素材、链接和排序规则一致；同 slug 可以跨两类内容使用，速览 id 包含类型以避免冲突。没有内容时显示本目录的空状态，不混入另一类作品。

## 12. 本地草稿查看

使用 `npm run dev:local` 时，真实文章、项目和玩具的草稿也进入列表与详情，合集保留草稿所属目录，顶部显示“本地预览”提示。这个例外只用于开发服务器，正式构建与普通 dev 继续隐藏草稿及仅草稿合集。不会展示 fixtures 示例或触发上传。
